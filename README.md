# Chatting App

A real-time chatting application built using React, Node.js, Express, and Socket.IO.

## Features

- User Login
- Real-time private messaging
- Multiple users
- Live chat updates
- Conversation history (in-memory)
- Responsive dark UI

## Tech Stack

- React
- Node.js
- Express
- Socket.IO
- CSS

## Run Locally

### Client

npm install
npm run dev

### Server

npm install
node index.js
